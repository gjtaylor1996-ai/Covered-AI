Covered — Investor Demo Hub

Everything built so far, in one place: click-through product prototypes for both sides of the marketplace, plus the business and fundraising materials.

How to use this: save every file from this package into the same folder, then open this page from there. The links below are relative paths — they only resolve correctly when all the files sit alongside each other. Suggested order: start at Log in, pick a role, and you'll land in the matching app.
What's new in this version
  • Founding venue programme — new document with the actual proposed terms: 8% commission, 15-venue cap, 90-day window, same-day support target, referral reward.
  • Venue outreach milestone plan — new phased go-to-market plan from first contact through to a liquid pilot, including activation tracking (not just signups) and explicit re-plan triggers if conversion or fill rate underperforms.
  • Financial model — added full P&L, Cash Flow Statement and Balance Sheet tabs, formula-linked to the same assumptions as everything else. Surfaces a real finding: at current assumptions, equity goes negative by Year 3 without a follow-on raise.
  • Technical specification — added an MVP phasing plan, the internal admin/dispute-review panel spec, a corrected multi-user venue data model, a role permission matrix, and race-condition handling for double-booking and concurrent disputes.
  • Client dashboard & worker app — added the permanent hire ("temp-to-perm") flow on both sides, with the UK Conduct Regulations 2003 fee/extension requirement built in.
  • Storage — favourites, onboarding state, and the connected demo now use browser-local storage instead of a Claude-only API, so everything still works once deployed to a real domain.
